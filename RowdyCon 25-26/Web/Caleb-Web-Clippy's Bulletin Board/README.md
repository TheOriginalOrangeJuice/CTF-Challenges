# Clippy's Bulletin Board

> **Category**: Web Exploitation
> **Difficulty**: Hard

## Description

The IT department at RowdyCon Systems has finally deployed their new company bulletin board on the intranet. Dave from IT assures everyone that it's "totally secure" — he even added DOMPurify!

But Clippy seems to think otherwise...

## Hints

1. Clippy knows more than he lets on. Listen to his advice!
2. Sometimes JavaScript trusts the DOM a little too much...
3. What happens when you name two things the same?
