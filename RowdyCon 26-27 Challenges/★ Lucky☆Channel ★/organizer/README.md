# ★ Lucky☆Channel — a hard web CTF challenge

A deliberately vulnerable early/mid-2000s **anime fan portal** ("Konata Izumi's
Otaku Densetsu HQ"): tiled starfield background, `<marquee>`s, 88×31 buttons, a
hit counter stuck at a leet number, a guestbook, animated GIFs, a retro media
player, a webring, and a members-only "Backstage." A *Lucky Star* parody/homage.

- **Category:** Web
- **Difficulty:** Hard — two bugs that must be **chained**
- **Flag:** configurable (see below); read at `/flag.txt` inside the container

> Full intended solution + reference exploit: see **[SOLVE.md](SOLVE.md)**
> (spoilers). This README is setup only.

---

## Quick start

```bash
docker compose up -d --build
# browse http://localhost:1337
```

Stop / reset (in-memory users + guestbook reset on restart):

```bash
docker compose down
```

Listens on **port 1337**. Fully self-contained — no outbound network needed for
the challenge itself, no headless-browser bot. Exploitable over plain HTTP.

## Configuring the flag

The flag is set by the `FLAG` environment variable at container start (an
entrypoint writes it to `/flag.txt`). Three ways:

**1. Inline env var**
```bash
FLAG='flag{your_custom_flag_here}' docker compose up -d --build
```

**2. A `.env` file** next to `docker-compose.yml`:
```
FLAG=flag{your_custom_flag_here}
```
then `docker compose up -d --build`.

**3. Plain `docker run`:**
```bash
docker build -t lucky-channel-ctf .
docker run -d -p 1337:1337 -e FLAG='flag{your_custom_flag_here}' lucky-channel-ctf
```

If `FLAG` is unset, a baked default flag is used. To rotate the flag on a
running stack, change it and `docker compose up -d` again (no rebuild needed —
the entrypoint re-writes `/flag.txt` on restart).

## Adding your own media (optional)

The site shows a **Fan Media Wall** on the home page built from whatever you put
in `static/media/`. That folder is mounted into the container read-only, so you
can add files **without rebuilding**:

```bash
cp ~/clips/my_amv.mp4      static/media/
cp ~/reactions/sparkle.gif static/media/
# refresh http://localhost:1337/
```

Supported: `.png .jpg .jpeg .gif .webp` (images) and `.mp4 .webm .ogg` (video).

The home page also embeds a **featured YouTube video** via YouTube's standard
player, and a "Now Playing" clip. The star/construction/character art under
`static/img/` is **original homage artwork** generated by `gen_media.py` — not
anime screenshots. If you have your own licensed Lucky Star clips/GIFs, drop
them in `static/media/` as above.

| path | what |
|------|------|
| `app.py` | the Flask app (both bugs live here, commented) |
| `gen_keys.py` | generates the RS256 keypair at image build |
