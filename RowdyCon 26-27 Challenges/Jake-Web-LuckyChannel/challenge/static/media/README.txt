Drop your own fan media here.
=============================

Any files you put in this folder show up in the "Fan Media Wall" section on the
Lucky Channel home page automatically -- no rebuild needed (this folder is
mounted into the container by docker-compose).

Supported:
  images : .png .jpg .jpeg .gif .webp
  video  : .mp4 .webm .ogg

Example:
  cp ~/Downloads/my_clip.mp4   static/media/
  cp ~/Downloads/sparkle.gif   static/media/

Then just refresh http://localhost:1337/ -- it'll be there.

Character portrait overrides
----------------------------
Name a dropped image exactly after a character and it REPLACES that character's
sidebar portrait (instead of showing on the Fan Media Wall):

  konata.*   kagami.*   tsukasa.*   miyuki.*     (any image extension)

e.g.  cp mypic.png  static/media/konata.png

Full-size pictures are fine -- the sidebar box auto-crops to the top-center of
the image (CSS object-fit: cover), so faces show without manual cropping.

(The .png/.gif art shipped under static/img/ is original homage artwork
generated by gen_media.py, not anime screenshots.)
