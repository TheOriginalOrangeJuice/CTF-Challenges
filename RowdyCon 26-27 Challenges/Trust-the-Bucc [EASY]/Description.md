# Trust-the-Bucc

## Description

My friend works at Buc-ee's now as their mascot. We were road-tripping and stopped at a gas station, which he then claims was the first Buc-ee's location he worked at.... but then why isn't it still a Buc-ee's? He couldn't answer so I'm having a hard time believing him. Here's a picture of the building. Can you tell me the store number of this Buc-ee's location... if it even was one. 

## Files

[storefront.jpg](../player/storefront.jpg) — one photograph. Submit `RCC{number}`.

## Walkthrough

1. Search for former Buc-ee's locations converted to Stripes. Mike's [Houston Historic Retail visit](https://houstonhistoricretail.com/2021/06/30/a-journey-through-buc-ees-turbulent-youth/comment-page-1/) contains the supplied photograph in its **El Campo** gallery. Match the taco sign, stone wall, canopy and ice machines. The preceding paragraph identifies **2403 N. Mechanic Street, El Campo, Texas**; the later Eagle Lake gallery is a different store.

   ![The saved visit identifies 2403 N. Mechanic Street immediately above the El Campo gallery.](screenshots/01-article-address.png)

2. Search the address with `Buc-ee's` to find the [historical fuel-location directory](https://nrha.com/media/pdf/partner/nfuelloc.pdf). Open PDF page **147** and locate `2403 N Mechanic`.

3. Read the same row: **Buc-Ee's #27**, El Campo, TX 77437. The requested former store number is **27**.

   ![Directory page 147: Buc-Ee's number 27 and the matching El Campo address.](screenshots/02-directory-row.png)
