# Description
I have been lost inside this stupid library, and I don't know the passcode to get out. This guy keeps babbling on about some dumb keys, but I don't know what he's talking about. Can you please help me?

# Walkthrough
The file consists of 30 lines, comprised of 15 large hex values and their respective wall, shelf, volume, and page. You use the hex value to find the hexagon. On each page, there is a certain english sentence mixed into the jumble. You are supposed to take the first character of the 15 sentences, and organize it into the flag. There are hints within the sentences to help you out if you are lost.
