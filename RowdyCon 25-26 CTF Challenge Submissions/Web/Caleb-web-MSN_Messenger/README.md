# MSN Messenger

> **Category**: Web Exploitation
> **Difficulty**: Hard

## Description

The IT department at RowdyCon Systems has deployed a web-based MSN Messenger client on the company intranet. Dave from IT assures everyone the session management is "totally locked down" — he even wrote a custom RestrictedUnpickler!

Sign in, chat with your buddies, and see if Dave's confidence is misplaced.

## Hints

1. The IT team says the session system is locked down. But what does "locked down" really mean when you control the cookie?
2. Not every query is created equal. Some are parameterized, some are... not.
