
#  CTF Challenges By Friends

This is a repository of all the challenges that were created or collected by me and friends. Mainly used for competition like UTSA RowdyCon or training resources.

Each folder is the year/event the challengers were made for. Some have extra content like a Jeopardy Board or Family Feud board that links to other repositories. 

Each challenge ideally has a Setup and Writeup Guide. Easy to spin-up and use!
